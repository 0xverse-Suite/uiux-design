# UI/UX Design

Public course workspace for research-safe briefs, wireframes, prototypes, design systems, case studies, and portfolio-ready product design.

**Course Lead:** To be assigned  
**Tutor team:** `@0xverse-Suite/uiux-tutors`  
**Student course team:** `@0xverse-Suite/uiux`

## Structure

- `briefs/` — assignment and project briefs
- `wireframes/` — lightweight exported wireframes
- `prototypes/` — preview exports and approved prototype links
- `design-systems/` — tokens, components, and guidance
- `case-studies/` — approved portfolio narratives
- `docs/` — research and process documentation

Workflow: brief → working branch/files → submission pull request → tutor review → revision → approval → portfolio-ready. Do not publish participant identities, raw research, or confidential client material. Prefer compressed previews and approved links for large source files. See [STUDENT_GITHUB_GUIDE.md](STUDENT_GITHUB_GUIDE.md).

Escalate research privacy, licensing, and publication questions to the tutor team.
