# Contributing

Start with an assigned Issue and its acceptance criteria. Use `feature/<github-username-or-team>/<task>` or `fix/<area>/<task>`, keep commits focused, and submit a pull request or documented review submission. Link the Issue with `Closes #<number>`, respond to tutor feedback, and merge only after approval.

Do not commit credentials, secrets, personal records, confidential briefs, restricted datasets, or unlicensed assets. Ask the tutor before publishing uncertain material.
